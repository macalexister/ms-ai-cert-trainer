DatenschutzKein Server, kein Konto, kein Tracking›
  • Was gespeichert wird — XP, Level, Abzeichen, Serie und die Statistik je Frage, ausschließlich im Speicher deines Browsers.
  • Was nicht passiert — keine Übertragung an einen Server, keine Analyse- oder Werbedienste, keine Cookies, keine Registrierung, keine Aufrufe an fremde Adressen.
  • Mehrere Personen — wer den Link öffnet, hat seinen eigenen getrennten Fortschritt. Niemand sieht die Ergebnisse der anderen.
  • Hosting — die Seite liegt auf GitHub Pages. Beim Abruf verarbeitet GitHub technisch nötige Verbindungsdaten wie die IP-Adresse, wie bei jeder Website.
  • Deine Kontrolle — „Fortschritt zurücksetzen“ löscht alle Daten sofort und vollständig. Das Löschen der Browserdaten für diese Seite wirkt genauso.
  • Rückmeldungen — was du unter „Rückmeldung“ schreibst, bleibt zunächst ebenfalls nur lokal. Erst wenn du auf „Senden“ tippst, öffnet sich dein E-Mail-Programm mit einem fertigen Entwurf an Alex Singer. Du siehst den Text vorher und schickst ihn selbst ab.
  • Keine internen Inhalte — die App enthält nur selbst formulierte Lerninhalte zu öffentlich dokumentierten Prüfungszielen. Gib auch selbst keine vertraulichen Daten ein; die App fragt keine ab.
